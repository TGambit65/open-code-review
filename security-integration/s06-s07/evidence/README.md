# Evidence locations and limits

prior-stages.json is a source-bound historical index to earlier review/preservation/offline results, not a copy of live authority or sensitive raw outputs. current-stage-state.json records authoring state only. Subsequent source seals, independent review, preservation and actual check receipts must be kept separately and bound to their exact source. No static status field can complete its own task.

The source traceability ledger points to these records where evidence remains unavailable. Host-controlled approved policy and authentic independent authority stay outside the candidate. Hash equality establishes identity only. No evidence file here authorizes a native run, provider, installation, sharing or activation.
